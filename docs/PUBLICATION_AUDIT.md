# Source publication status

Source is public at https://github.com/dnsklchn0318/tuipo-ru.
The publication copy preserves upstream attribution and uses the maintainer's GitHub
login/noreply identity. Local home paths, historical .DS_Store and obsolete demo images
were removed in that copy; original local history is retained privately.

Version 0.4.0 restores the intended terminal workflow for Codex CLI in Terminal.app,
keeping corrected ZIP/LRU dependencies. Version 0.3.0's file-only architecture is
historical, not the primary interface. The optional file checker remains available.

Source publication, binary packaging and installation are separate actions. No shell
profile, system setting or Codex configuration is changed. The prepared local binary
archive includes sources and notices; no binary release is automatically published.
See VALIDATION.md, DEPENDENCY_REACHABILITY.md and THIRD_PARTY_NOTICES.md.
