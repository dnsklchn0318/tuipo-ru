# Version 0.4.0 — terminal workflow

Source: https://github.com/dnsklchn0318/tuipo-ru

Build with `cargo build --locked --release`; launch with
`./target/release/tuipo -- codex` from the source directory. In the prepared macOS
ARM64 archive, launch `./tuipo -- codex`. To use another project directory, invoke
the binary by absolute path after changing to that project directory.

The local archive contains the executable, instructions, source snapshot, dependency
sources, license declarations, original notices and dictionary notices. Build paths
are remapped. No system installation or automatic shell integration is performed.
The archive is prepared locally; it is not automatically uploaded as a GitHub release.
