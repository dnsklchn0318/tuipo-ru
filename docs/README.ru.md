# Tuipo для Codex CLI в Terminal.app

Версия 0.4.1 проверяет русский и английский текст прямо во время набора в Codex.

Из каталога проекта:

```sh
cargo build --locked --release
./target/release/tuipo -- codex
```

Уже запущенную сессию Codex нужно завершить и запустить этой командой.
Из распакованного архива команда короче: `./tuipo -- codex`.
Чтобы работать в другом проекте, перейдите в его каталог и укажите полный путь
к `tuipo`, затем `-- codex`.

Напишите `превет world `, дождитесь подчёркивания, поставьте курсор в ошибочное
слово или сразу после него. Ctrl+N открывает варианты; Ctrl+N/P листают их,
Enter подтверждает выбранный вариант, Escape закрывает меню. После исправления
отправка сообщения выполняется отдельным Enter. Tab сохраняет обычное поведение.

Проверка орфографии локальная; Tuipo не отправляет текст сервису проверки,
не сканирует проект и не читает .env. Обрабатывается ввод выбранной терминальной
сессии. Работа сети самого Codex от Tuipo не зависит.

Для запуска без проверки используйте обычную команду `codex`. Никакой демон или
интеграция shell автоматически не устанавливается. `tuipo off` отключает обработку;
`tuipo on` включает её для следующих запусков — после него нужно перезапустить Codex.

Настройки: `$XDG_CONFIG_HOME/tuipo/config.toml` или `~/.config/tuipo/config.toml`.
Оба языка и исправления включены по умолчанию. Пользовательский словарь исключений —
`dict.txt` рядом с конфигом. Полный пример: [README](../README.md).

`tuipo check -- файл.txt` сохранён как дополнительный режим проверки файлов.
Он не требуется для проверки при наборе. Результаты тестов: [VALIDATION.md](VALIDATION.md).

Для более заметных ошибок без ярких цветов задайте `underline = "highlight"`
в конфиге: светлый текст на приглушённом бордовом фоне. `underline = "auto"`
возвращает прежнее подчёркивание.
