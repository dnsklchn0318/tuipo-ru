# tuipo-ru

Локальная проверка русского и английского текста в явно указанном файле:

```sh
cargo build --locked --release
./target/release/tuipo check -- draft.txt
```

Результат: `строка:столбец: слово -> варианты`. Строки и столбцы считаются с 1;
столбец измеряется Unicode-символами. Файл не изменяется. Коды завершения: 0 —
замечаний нет, 1 — найдены замечания, 2 — ошибка. Поддерживаются обычные UTF-8
файлы до 1 МиБ; симлинк вместо файла и специальные файлы отклоняются.

Tuipo не перехватывает сессию Codex, не читает буфер обмена и не устанавливает
интеграцию оболочки. Редактируйте текст своим редактором, проверяйте файл, затем
переносите текст самостоятельно. Если явно выбранный файл содержит секрет,
проверяющий процесс прочитает его. Результаты проверки могут содержать этот текст.

Настройки и ограничения описаны в [README](../README.md). Старые параметры
терминального интерфейса больше не поддерживаются; автоматической миграции нет.
Публикация исходников, выпуск бинарников, установка и запуск оцениваются отдельно.
Отчёты: [публикация](PUBLICATION_AUDIT.md), [зависимости](DEPENDENCY_REACHABILITY.md),
[проверки](VALIDATION.md). Предупреждения о неподдерживаемых библиотеках не скрываются.
